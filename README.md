# Daily Spark

Create a modern, mobile-friendly "Daily Motivation" website.

Features:

- Show a new motivational quote every day.

- Add a "Next Quote" button to display another quote.

- Display the author below each quote.

- Add beautiful gradient backgrounds with smooth animations.

- Include categories: Success, Self Confidence, Study, Fitness, Life, Happiness.

- Add a search bar to find quotes.

- Allow users to save favorite quotes.

- Include a dark mode and light mode toggle.

- Add a "Copy Quote" button and a "Share" button.

- Make the UI clean, premium, and responsive with attractive fonts and icons.

- Add a welcome message: "Start your day with positivity."
